# Support

For setup and usage, start with the [installation guide](docs/INSTALLATION.md), [user guide](docs/USER_GUIDE.md), and [troubleshooting guide](docs/TROUBLESHOOTING.md).

If the answer is not there:

- Use GitHub Discussions for questions and configuration help.
- Open a bug report for a reproducible defect.
- Open a feature request for a new behavior.
- Use private vulnerability reporting for security issues.

Include the Live Canvas version, Obsidian version, operating system, relevant settings, and minimal reproduction steps. Remove private note names and content before posting.
