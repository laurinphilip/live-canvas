# Live Canvas demo notes

Copy the `Knowledge` folder into a test vault, then configure Live Canvas as follows:

- Source filter: `Folder`
- Source folder: `Knowledge`
- Linked neighbors: `One link away`
- Neighbor direction: `Incoming and outgoing`
- Label relationships: enabled
- Category colors:

  ```text
  tag:empire = 1
  tag:person = 4
  tag:event = 6
  ```

Select **Refresh and open**. Move a card, add a manual text card, edit a note, and refresh again to verify that your layout and manual content are preserved.
